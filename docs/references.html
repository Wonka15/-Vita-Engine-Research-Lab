02 · Bungie's Blam! engine lineage

Historical architecture study · 1997 onward
Engine evolution timeline

From Blam! to Tiger

Follow the Bungie engine across Halo: Combat Evolved, Halo 2, Halo 3, Halo 3: ODST and Halo: Reach. ODST is a case study in extending a mature Halo 3 engine; Reach is the important bridge toward the foundation and job-system work that fed into Tiger and Destiny.

  • Original Blam! era: Halo CE, Halo 2, Halo 3, ODST and Reach.
  • Internal experiments: Phoenix and Gypsum, named in Chris Butcher's GDC 2015 talk.
  • Related use: Stubbs the Zombie used Halo engine technology outside the Halo series.
  • Later descendants: Bungie's Tiger / Destiny branch and later 343 Industries Halo engine generations are identified separately.
  • Not the same engine: Halo Wars used Ensemble Studios' separate Phoenix engine.

05 · How we validate

Separate evidence by environment
Browser graphics labFast visual prototyping, interaction and diagnostics. Not a Vita emulator or hardware benchmark.
Vita3K emulatorNative VPK launch, runtime smoke tests and regression captures. Not proof of physical-device performance.
Physical PS VitaRequired for hardware claims: frame timing, memory pressure, GPU behaviour, input and compatibility.
Evidence labels: Documented · Source-confirmed · Emulator-tested · Hardware-tested · Hypothesis. Every benchmark should record build revision, device, settings, frame-time distribution, memory estimate and known limitations.

06 · Licensing & intellectual property

  • Commercial game references are for public research. Do not extract or commit proprietary source, shaders, tools, textures, models, maps, audio or game data.
  • Public source code is not automatically reusable. Check the exact file, revision, license, submodules, dependencies and notices.
  • Keep provenance records for every third-party component actually incorporated.
  • The repository's MIT license applies to original project material only; it does not relicense third-party work or grant rights to game IP.
  • Prefer independent implementations of useful ideas.
