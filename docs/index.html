Getting started

Install VitaSDK (WSL2 is the recommended Windows route), build vitaGL separately, then build the First Light VPK. Follow the guide for installation and hardware evidence labels.

cd Prototypes/FirstLight
cmake -S . -B build -DCMAKE_TOOLCHAIN_FILE="$VITASDK/share/vita.toolchain.cmake"
cmake --build build --parallel
